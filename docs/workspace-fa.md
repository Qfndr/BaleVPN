# رابط تب‌بندی‌شدهٔ BaleVPN

از نسخهٔ ۲٫۳٫۰، رابط دسکتاپ و صفحهٔ مدیریت تحت وب تب‌های مستقل دارند. نسخهٔ ۲٫۴٫۰ تب هفتم، «تجمیع تونل‌ها»، را اضافه می‌کند. در دسکتاپ منوی کناری و در نمایشگرهای کوچک تب‌های بالای صفحه دیده می‌شوند. فارسی، راست‌به‌چپ، فونت وزیرمتن و Inter و تنظیمات ظاهری قبلی حفظ شده‌اند.

| تب | کاربرد |
| --- | --- |
| اتصال | انتخاب نقش، ورود، انتخاب حساب سرور، پورت SOCKS5 و اتصال/قطع اتصال |
| ترافیک و آمار | حجم‌ها، میانگین و اوج سرعت، نمودار زنده، انتخاب واحد و CSV |
| تجمیع تونل‌ها | مدیریت نمونه‌های مستقل حساب و تقسیم اتصال‌ها بین چند تونل؛ [راهنمای چهارحسابی](multi-tunnel-fa.md) |
| مدیریت کلاینت‌ها | درخواست‌های در انتظار، کلاینت‌های متصل، فهرست مجاز و مسدود و ظرفیت سرور |
| امنیت و جفت‌سازی | کد عمومی دستگاه، اعتماد به همتا و الزام رمزگذاری تأییدشده |
| تنظیمات اتصال | پروفایل انتقال و محدودیت دفعات تماس |
| شخصی‌سازی | زبان، تم روشن/تاریک/سیستم، پالت و رنگ دلخواه، فونت، اندازه، عرض، فاصله‌ها، گوشه‌ها و کاهش حرکت |

تنظیمات ظاهر همان لحظه روی همین دستگاه ذخیره می‌شوند. تغییرهای امنیت و عملکرد با دکمهٔ «ذخیرهٔ تنظیمات» اعمال می‌شوند و برای اتصال بعدی‌اند؛ پیش از ذخیره، تونل را قطع کنید. عوض‌کردن تب، تنظیمات امنیت یا اتصال را ذخیره نمی‌کند و تماسی برقرار نمی‌کند. ورودی‌های ذخیره‌نشده هنگام جابه‌جایی بین تب‌ها باقی می‌مانند.

تب آمار مخصوص نقش کلاینت است؛ در نقش سرور از تب مدیریت کلاینت‌ها استفاده کنید. تا پیش از ورود، این تب‌ها راهنمای شروع را نشان می‌دهند. نقش و وضعیت واقعی اتصال در سربرگ و منوی کناری مشخص‌اند؛ قطع پاسخ وضعیت محلی به صورت «وضعیت در دسترس نیست» نمایش داده می‌شود.

برای کار با صفحه‌کلید، روی یکی از تب‌ها فوکوس کنید و از کلیدهای جهت‌دار، Home و End استفاده کنید. جهت حرکت افقی با زبان فارسی هماهنگ می‌شود. کاهش حرکت سیستم و گزینهٔ برنامه روی انیمیشن کوتاه تغییر تب و افکت سرعت اعمال می‌شوند.

رابط بدون کتابخانهٔ خارجی یا درخواست فونت از اینترنت اجرا می‌شود. مسیر انتقال، رمزگذاری، اندازهٔ صف‌ها و پنجره‌های پیش‌فرض تغییری نکرده‌اند. نمودار از همان نمونه‌برداری قبلی استفاده می‌کند؛ تغییر تب نمونه‌برداری یا تست سرعت جدیدی ایجاد نمی‌کند.

راهنمای آمار و افزایش سرعت: [سرعت و آمار ترافیک](traffic-dashboard-fa.md).

## آزمون توسعه‌دهنده

آزمون‌های خودکار بدون وابستگی مرورگر:

```sh
node --test scripts/test-ui-security.cjs scripts/test-ui-traffic.cjs scripts/test-ui-workspace.cjs scripts/test-ui-aggregate.cjs
```

برای بررسی واقعی رابط، `scripts/test-ui-workspace-browser.cjs` را با Playwright نصب‌شده در محیط توسعه اجرا کنید. مسیر ماژول و فایل مرورگر را در `BALEVPN_PLAYWRIGHT_MODULE` و `BALEVPN_BROWSER_EXECUTABLE` قرار دهید. متغیر اختیاری `BALEVPN_SCREENSHOTS` پوشهٔ تصاویر پیش‌نمایش را تعیین می‌کند. این آزمون فقط از سرور محلی ساختگی استفاده می‌کند؛ تصاویر و ترافیک آن اندازه‌گیری سرعت واقعی نیستند و حساب بله‌ای استفاده نمی‌شود.
