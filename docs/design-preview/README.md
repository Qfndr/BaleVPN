# پیش‌نمایش تاریخی پیشنهاد اول نوا

`index.html` را با مرورگر باز کنید. فونت‌ها از فایل‌های موجود پروژه خوانده می‌شوند؛ نصب وابستگی یا اتصال اینترنت لازم نیست. حساب‌ها، وضعیت امنیت و سرعت‌ها کاملاً نمایشی هستند. دکمه‌های اتصال و تجمیع فقط وضعیت پیش‌نمایش را تغییر می‌دهند. افزودن حساب فعلاً محل پیشنهادی ورود را توضیح می‌دهد و ورود واقعی ندارد.

این پوشه مربوط به مرحلهٔ اولیهٔ طراحی است و با طراحی بازسازی‌شدهٔ 2.6.3-dev.2 یکسان نیست. برای ارزیابی نسخهٔ فعلی، تصاویر ثبت‌شده از رابط اصلی در پوشهٔ Previews بستهٔ تست و خود فایل اجرایی را ببینید؛ این نمونه مرجع ظاهر نهایی نیست. راهنمای پیاده‌سازی قابل اجرا با سه طراحی کلاسیک، نوا و مدار در [راهنمای نسخهٔ تست](../ui-three-designs-fa.md) است.

## جریان پیشنهادی

- تب اتصال: افزودن و انتخاب حساب؛ نمایش تنظیمات همان حساب شامل سرور، پورت، اتصال مجدد و پروفایل عملکرد؛ اتصال و قطع مستقل.
- تب تجمیع: انتخاب تونل‌های آماده و سیاست تقسیم درخواست‌ها؛ یک پروکسی خروجی. توقف تجمیع نباید تونل‌های مستقل را قطع کند. این تقسیم اتصال‌ها است و افزایش سرعت دانلود تک‌اتصالی را تضمین نمی‌کند.
- ظاهر: طراحی فعلی در برنامه حفظ می‌شود و نوا گزینهٔ دوم خواهد بود. کارت «ساده» در این پیش‌نمایش یک نمونهٔ جایگزین است و بازسازی دقیق رابط فعلی نیست.
- تنظیمات پیشرفته به‌صورت بازشونده، کنار حساب مربوط؛ وضعیت خلاصهٔ اتصال و ترافیک همیشه قابل مشاهده.

## کار پس از تأیید طراحی

1. رفع ماندگاری واقعی زبان، تم، رنگ و سبک طراحی: ذخیرهٔ اتمی تنظیمات غیرحساس ظاهر در پوشهٔ دادهٔ کنترل‌کننده، بازیابی هنگام شروع و پشتیبانی از انتخاب‌های محلی قبلی. اکنون رابط اصلی فقط از localStorage استفاده می‌کند؛ علت دقیق از دست رفتن تنظیمات باید در اجرای بومی و با تغییر پورت پنل بازتولید شود.
2. مدیریت حساب‌ها و اجرای workerهای مستقل از تب اتصال، با مسیر داده و تنظیمات جدا؛ تغییر حساب نباید تنظیمات ذخیره‌نشده یا وضعیت حساب دیگر را مخلوط کند. استفاده از proxy پروفایلِ هم‌مبدأ موجود به‌جای URL دلخواه یا iframeهای متعدد.
3. اتصال تب تجمیع به وضعیت واقعی و فقط انتخاب مسیرهای آماده؛ حفظ امکان اتصال مستقل بدون تجمیع.
4. اعمال نوا به‌عنوان سبک قابل انتخاب همراه با طراحی فعلی؛ هماهنگی تم در پنجرهٔ بومی، پنل‌ها و فارسی/انگلیسی.
5. آزمون باز و بسته‌کردن واقعی برنامه، ورود مجدد پنل، تغییر پورت، استقلال حساب‌ها، خطای ذخیره‌سازی، قطع و وصل شبکه، و مقایسهٔ مصرف منابع و توان عملیاتی قبل و بعد. تصاویر این پوشه و آزمون مرورگر فقط پیش‌نمایش را تأیید می‌کنند.

فایل HTML این پوشه مستقل از برنامه است و هیچ دادهٔ واقعی حسابی نمی‌خواند. فقط تنظیمات غیرحساس خودش را با کلید مجزای `balevpn-nova-preview` در مرورگر ذخیره می‌کند.

برای بازتولید تصاویر با Playwright نصب‌شده، متغیرهای `BALEVPN_PLAYWRIGHT_MODULE` و `BALEVPN_BROWSER_EXECUTABLE` را مطابق توضیح ابتدای `check-preview.cjs` تعیین و `node docs/design-preview/check-preview.cjs` را از ریشهٔ پروژه اجرا کنید. ابزار مرورگر یا فونتی دانلود نمی‌شود.
