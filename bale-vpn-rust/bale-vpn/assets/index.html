Why can speed be limited?

400 KB/s is about 3.2 Mbps. RTT, packet loss, peer windows and the carrier can limit speed. Try Throughput on both peers after disconnecting. The window/RTT number is a local estimate, not a guaranteed ceiling. KB means 1,000 bytes. Charts pause while this window is hidden.

Independent tunnels. One local proxy.

Distributes separate TCP connections, not packets of one stream. Multi-part downloads can use several tunnels. A single-stream download does not get bonded. No direct-internet fallback.

Distribution policy

Weights affect distribution of new connections. Existing streams remain on their original tunnel. Backups are tried before application data is forwarded; interrupted streams need retry.

Four-account setup

Add each client account here, sign in inside its account panel, select its server and save secure pairing. Then connect the accounts and start the local pool. Two independent pairs use four accounts; both servers may share one VPS. Starting the pool does not place calls.

Only add trusted local BaleVPN SOCKS ports. Verify encryption in each profile. Keep management ports private; use SSH forwarding on a remote server. More calls do not guarantee higher speed or prevent account restrictions.

What is inside the encrypted file?

Existing access tokens, original device identities, pairing keys and account settings. Password protection uses AES-256-GCM and PBKDF2-SHA256. Keep the file and password private and separate. Import does not bypass session expiry or Bale security checks.
