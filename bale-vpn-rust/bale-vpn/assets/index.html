Why can speed be limited?

400 KB/s is about 3.2 Mbps. RTT, packet loss, peer windows and the carrier can limit speed. Try Throughput on both peers after disconnecting. The window/RTT number is a local estimate, not a guaranteed ceiling. KB means 1,000 bytes. Charts pause while this window is hidden.
